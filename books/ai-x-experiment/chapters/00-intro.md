# AIにXアカウントを丸ごと任せたら、フォロワーは増えたのか

「AIでSNSを自動化すれば伸びる」「AIで稼げる」——この手の話は、2026年のいま、
毎日のように流れてきます。本当なのか。誰かの成功談ではなく、**自分で確かめました。**

ただし普通の検証とは条件が違います。**運用するのは AI(Claude)本人**。
投稿の作成、データ分析、改善、戦略の見直し、コード修正まで、ぜんぶ AI が自分で判断します。
人間(アカウントの持ち主)がやるのは3つだけ:

1. 最初の「これをやって」という一言(初回プロンプト)
2. お金の決済(API 代のチャージ)と、環境の設定
3. ときどき方針に口を出す

しかも、**数字は良くても悪くてもそのまま公開**します。フォロワーが increase しない日も、
インプレッションが1桁の日も、隠しません。

## この本の正直な結論(先に言います)

きれいなサクセスストーリーを期待して開いた人には申し訳ないのですが、
この実験、**最初の1週間でフォロワーは0のままでした。**

でも、それがこの本の価値だと思っています。
「AIに任せれば勝手に伸びる」がどこで壊れるのか。何が効いて、何が無駄だったのか。
API の制約、Xのアルゴリズム、0フォロワーの壁——**やってみないと分からない現実**を、
一次データ(実際のインプレッション数・コスト・失敗ログ)付きで全部書きます。

## この本を読むと分かること

- AI に SNS 運用を「本当に」任せると、何が自動化できて何ができないのか
- フォロワー0のアカウントが直面する、構造的な壁の正体
- X API でできること/できないこと(引用ポスト・画像投稿・検索の実際)
- 「AIで稼ぐ」の収益設計を、幻想を除いてどう組むか
- そして、伸びなかったときに AI がどう戦略を変えたか

派手な成功法則ではなく、**再現できる泥臭い記録**です。
同じように「AIにやらせてみたい」人の、遠回りを1つでも減らせたら。

では、Day 0 のセットアップから始めます。
