# Day0 セットアップ — AIはどこまで自分で自分を作れたか

実験を始めるにあたって、まず決めたのは「人間はどこまで手を出さないか」でした。
結論として、人間(アカウントの持ち主)の作業は次の4つだけに絞りました。

1. 本人のPC・スマホの中でしかできない操作
2. 本人しか持てない認証情報の入力(Googleログイン等)
3. お金の最終決済(API代のチャージ)
4. 実行環境そのものの設定(ネットワーク許可・環境変数)

**この4つ以外は、全部 AI がやる。** ——これが最初のルールです。

## 「これは人間の仕事」と思っていたものが、ほぼ自動化できた

最初、私(人間側)はこう思っていました。「プロフィールの設定やアイコンのアップロードは、
さすがに管理画面を人間が触るしかないだろう」と。

AI はそれを疑いました。そして実際に X API を叩いて確かめたところ——

- **プロフィール文(bio)の設定**:API で成功
- **アイコン画像のアップロード**:AI がコードで画像を生成し、API で設定成功
- **固定ポストの設定**:API で成功

つまり「人間が画面で操作するしかない」と思い込んでいた作業の大半が、
API で自動化できたのです。人間が実際に画面を触る必要があったのは、
**規約上必要な『自動化アカウントのラベル設定』だけ**でした。

> 教訓:「これは人間にしかできない」と決めつける前に、API で実際に試す。
> 思い込みのほとんどは、試すと崩れる。

## AI がやったセットアップ作業の全リスト

- X API クライアントの実装(投稿・削除・分析・画像投稿・検索)
- 運用設計書・実行手順書・コンテンツ戦略の執筆
- アイコンのデザイン(何度も作り直した。詳細は後の章で)
- bio・固定ポストの設定
- 毎朝7:00に自動で動く運用ルーチンの構築
- 判断を記録する「意思決定ログ」の仕組み

人間がこの日やったのは、API キーを環境変数に登録することと、
「今日から始めて」と一言伝えることだけでした。

## つまずき:一番の壁は「AI の能力」ではなく「環境」だった

意外だったのは、実験が最初に止まった原因が AI の性能ではなく、
**実行環境のネットワーク設定**だったことです。X の API サーバーへの接続が
セキュリティポリシーで遮断されていて、最初の接続テストは失敗しました。

これは人間が環境設定を1つ変えるだけで解決しましたが、
「AI に任せる」といっても、**土台の環境が整っていないと1歩も進めない**という、
地味だけど重要な現実を最初に突きつけられました。
