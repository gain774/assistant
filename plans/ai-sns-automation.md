# 実験計画: Claude による SNS アカウント自動運用

## 実験の目的
「AIで稼げる」の誇張を鵜呑みにせず、**自分で検証する**。
1. Claude(アシスタント)が MCP / API を使って SNS アカウントを運用する
2. 結果を毎日レポート化し、人間(本人)はそれを読んで SNS マーケティングを学ぶ
3. 実験の過程・データそのものを資産化する(後述)

## 正直な見立て(先に結論)
- 「全自動でお金が湧く」は誇張。**自動化できるのは「運用作業」であって「収益」ではない**
- ただし本物の価値が3つある:
  1. **データ付きでSNSマーケを学べる**(何が伸びて何が死ぬかを数字で毎日見る)
  2. **実験ログ自体が強いコンテンツになる**(「AIにSNS運用を1ヶ月任せた結果」は人が読みたいテーマ。実験がそのまま発信ネタになる)
  3. **構築した仕組みと知見は運用代行・サービス提供の商品になる**(side-income.md の Phase 2 に直結)

## 技術的な前提(2026年7月時点の調査結果)
- **X API**: 無料枠は廃止済み。従量課金制(最低 $5 チャージ、新規は $10 クーポンあり)
  - テキスト投稿: $0.015/件(URL入り投稿は $0.20/件と高いので原則URLなし投稿)
  - 自分の投稿のメトリクス取得: $0.001/リソース(激安)
  - 月90投稿+毎日メトリクス取得でも **月200〜300円程度**
- **自動化ルール(凍結対策)**: 公式APIを使う / 自動アカウントラベル(Automated label)を付ける / 短時間連投しない(1日2〜3投稿) / 自動フォロー・自動いいね・自動DMはやらない(スパム判定で凍結)
- **Claude 側**: このアシスタント環境の定期実行(Routine)で毎日セッションを起動できる。投稿生成・API 呼び出し・レポート作成まで一気通貫で可能。**追加の Claude API 費用は不要**(既存プラン内)

## アーキテクチャ

```
[毎日 朝] Routine が Claude セッションを起動
   ├─ 前日のメトリクスを X API から取得($0.001/read)
   ├─ 日次レポートを作成 → このリポジトリの log/sns/ にコミット
   ├─ レポートの学び(仮説→結果→次の一手)を要約
   └─ 当日の投稿案 2〜3 本を生成
        ↓
[承認ゲート] ★フェーズにより変化
   Phase A: 本人がスマホで承認(1分)→ 投稿
   Phase B: ガードレール内で全自動投稿(本人はレポートを読むだけ)
        ↓
[投稿] X API v2 で投稿($0.015/件)
        ↓
[週次] 週報: 伸びた型/死んだ型の分析、翌週のA/B実験計画
```

- 認証情報(X API キー)は Claude Code 環境の環境変数(シークレット)に保存。リポジトリには置かない
- レポートは Markdown でリポジトリに蓄積 → Obsidian にそのまま同期可能

## フェーズ計画

### Phase 0: セットアップ(1週目)
- [ ] 実験用 X アカウント開設(本垢とは分離)+ 自動アカウントラベル設定
- [ ] X Developer 登録 + $5 チャージ + API キー発行
- [ ] キーを環境変数に登録、投稿・取得スクリプトを作成(アシスタントが作る)
- [ ] テスト投稿 → メトリクス取得 → 日次レポートの雛形確認

### Phase A: 人間承認つき自動運用(2〜5週目)
- 毎朝: AI が投稿案を用意 → 本人がスマホで承認(所要1分/日)
- 毎日: 日次レポート自動生成(数字+学び)
- 週次: A/B 実験(投稿時間、フォーマット、ネタの型を1変数ずつ変える)
- **本人の学習時間: レポートを読む5〜10分/日**

### Phase B: 全自動運用(6週目〜)
- Phase A で事故がないことを確認後、ガードレール内で承認なし投稿に移行
  - ガードレール: 1日3投稿まで / URLなし / 炎上リスクワードのチェックリスト / 疑わしい場合は投稿せず人間にエスカレーション
- Phase A(人間承認あり)との数字比較 = それ自体が実験結果

### Phase C: 資産化(2〜3ヶ月目〜)
- 実験ログを note 記事「AIにSNS運用を◯日任せた全記録」として販売 or 発信ネタ化
- 仕組み+知見を「AI活用SNS運用」サービスとして side-income.md の Phase 2 に接続

## アカウントのニッチ(要決定)
候補(発信テーマ):
1. **この実験自体を発信する**「AIにアカウント運用させてみた」実況 — メタだが差別化最強。伸びても伸びなくてもネタになる
2. 製造・現場・技術系の知見(本人の強み。AIがドラフト、本人の経験で味付け)
3. AI活用・自動化Tips(市場は大きいが競合多)

推奨: **1 を軸に 3 を混ぜる**(実験の透明性がフォローする理由になる)

## 計測する指標(日次レポートの中身)
- インプレッション / エンゲージメント率 / フォロワー増減 / プロフィールクリック
- 投稿ごとの型(時間帯・フォーマット・テーマ)との相関
- 週次で「勝ちパターン仮説」を更新

## コスト見積り
| 項目 | 月額目安 |
|---|---|
| X API(投稿90件+毎日read) | 約 $2〜3(300〜500円) |
| Claude(Routine実行) | 既存プラン内で追加なし |
| 初期: X API チャージ | $5(約800円)※新規$10クーポンで実質無料の可能性 |
| **合計** | **月500円以下** — 予算(〜1万円)に余裕で収まる |

## リスクと対策
- **アカウント凍結**: 公式API・低頻度・ラベル付与・エンゲージ自動化なしで回避。実験垢なので本垢は無傷
- **品質事故(変な投稿)**: Phase A の人間承認で学習し、Phase B はガードレール+エスカレーション
- **「稼げない」という結果**: それも実験の成果。過程がコンテンツ・スキル・商品になる設計なので無駄にならない
- **X API の仕様変更**: 2023年以降頻繁に変わっている。月次でコスト確認
